Plots

Syntax & function reference
  • Variables — a = 5 constant (slider, default range [0,10]); a = 5 {0,100} sets slider range; a bare a defaults to 1.
  • Independent vars — x = independent {0, 1} declares an x-axis variable with its domain (defaults to {0, 1}). Each one a function uses renders a separate plot.
  • Functions — y = expr. Click or drag a plot to place a marker; markers on a shared variable update every plot together.
  • Comments — lines starting with # or // are ignored.
  • Operators — + - * / % ^, comparison == != < <= > >=, logical and or, ternary ? :.
  • Constants — PI, E.
  • Functions — sin cos tan asin acos atan atan2 sinh cosh tanh sqrt exp log log2 log10 abs floor ceil round trunc min max sign clamp lerp smoothstep step mod.
